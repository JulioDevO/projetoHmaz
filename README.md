# Grupo Hmaz - Sistema de Gestão ERP (Protótipo Front-end)

Protótipo de alta fidelidade desenvolvido para a gestão de produção, controle de ordens de serviço, análise de dados e diretório de clientes/máquinas do Grupo Hmaz. 

## 🚀 Tecnologias Utilizadas

* **React** (Biblioteca de interfaces)
* **Vite** (Build tool e servidor de desenvolvimento rápido)
* **Tailwind CSS** (Estilização utilitária)
* **React Router DOM** (Navegação SPA)
* **Lucide React** (Ícones)

## ⚙️ Pré-requisitos

Antes de começar, você vai precisar ter instalado em sua máquina a seguinte ferramenta:
* [Node.js](https://nodejs.org/en/) (que já inclui o gerenciador de pacotes `npm`).

## 🛠️ Como baixar e rodar o projeto localmente

1. **Clone este repositório:**
   ```bash
   git clone [https://github.com/https://github.com/JulioDevO/projetoHmaz.git](https://github.com/https://github.com/JulioDevO/projetoHmaz.git)

## 1. Instale as dependências necessárias:
    npm install

## 2. Inicie o servidor de desenvolvimento:
